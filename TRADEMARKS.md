# The Terrabots name

The code is open under the [Mozilla Public License 2.0](LICENSE). The license
covers the code, not the name: it grants no rights to "Terrabots" or its logo
(MPL-2.0 §2.3). This page says how to use the name so that people always know
what they are looking at.

## Fine without asking

- Running Terrabots, publicly or privately, for free or paid: a class server, a
  tournament, a hosted arena, a course.
- Saying what it is: "powered by Terrabots", "based on Terrabots", "a Terrabots
  server", "lessons for Terrabots".
- Naming your bots, notebooks, tutorials and videos about Terrabots after it
  ("Terrabots targeting tutorial").
- Unchanged copies and packages of the official releases.

## Please don't

- Call a fork, a changed version or a hosted service "Terrabots" on its own, or
  present it as the official project. Give it its own name and say it's based on
  Terrabots, e.g. "Ironclad Arena, based on Terrabots".
- Remove the copyright and license notices, or the link back to the project, from
  the setup screen, website or docs you serve.
- Imply that André Munzinger or the Terrabots project endorses your product,
  service or tournament unless that was agreed.

## Hosting a server

Go ahead. Keep a visible "powered by Terrabots" with a link to the project and,
if you changed the engine, link to the source of your
changes: the MPL asks for that when you distribute changed files, and it helps
everyone even when you only host. Better still, send the changes upstream as a
pull request.

Not sure whether a use is fine? Open an issue and ask.
