# Community bots

Bots submitted by the community. Each author has a folder named after their GitHub
user name:

```
contrib/
  your-github-name/
    __init__.py        # empty
    my_tank.py         # one or more BattleAgent (battle) or Agent (survival) classes
```

Bots here appear in the setup screen ("Community bots") and take part in the
weekly tournament that builds the [leaderboard](../docs/leaderboard.md).
How to submit: [CONTRIBUTING.md](../CONTRIBUTING.md#submit-a-bot).
